# i18n

Catalogs: `src/lib/i18n/locales/{en,ms}/<namespace>.json`. Starter namespaces: `common`, `errors`, `order`. Keep both locales structurally identical. Types come from the `en` JSON.

Detection order: `?lang=`, then `sessionStorage`. Fallback is `en`. Navigator and cookie detection are off. `document.documentElement.lang` stays in sync.

Use `setAppLanguage()` to change language. Use `pickLocalized({ en, ms })` for CMS payloads.

Do not hardcode user-facing strings in components.
